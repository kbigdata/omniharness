# 하네스 가정 대장 (화석화 방지) — GAP §4.3

> 하네스 구성요소는 "모델이 혼자 못하는 것"에 대한 가정을 인코딩한다. **모델이 발전하면 가정은 낡는다.**
> 모델 업그레이드마다 아래 "보완 대상"을 재검증하고, 불필요해진 장치는 제거(dead weight 방지)한다.

| 구성요소 | 보완하는 모델 약점 | 모델 발전 시 재검증 포인트 |
|---|---|---|
| `policy.PermissionPolicy` (can_use_tool deny/ask) | 위험·파괴 명령을 제안할 수 있음 | 항상 유지(untrusted-by-default). deny-list 패턴만 점검 |
| `backend` 블록=클래스명 파싱 | SDK 메시지 구조 의존 | **SDK 버전업 시 필수 재검증**(TextBlock/ToolUseBlock 구조) |
| `verify.FreshEvaluator` (resume 금지) | 자기 산출 과대평가(매몰비용) | 자기평가 편향이 줄면 신선분리 완화 검토 |
| `loop.run_until_verified` | 한 번에 "완료" 조기선언 | 모델이 스스로 끈질겨지면 외부 반복 축소 검토 |
| `handoff.FeatureList`/decompose | 원샷 시도→컨텍스트 고갈 | 컨텍스트 윈도우 커지면 분해 강도 완화 검토 |
| `gate.SkillGate` (deny-list·dedup) | 자기생성 스킬은 신뢰 불가 | 항상 유지(안전). 임계치만 조정 |
| `wiki.lint` | 오래된 지식이 가장 위험 | 항상 유지. 규칙 보강 |

> 코드 각 모듈 docstring에 "보완 가정(GAP §4.3)" 주석으로도 명시돼 있다.
