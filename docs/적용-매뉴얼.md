# omniharness 적용 매뉴얼 (새 프로젝트)

omniharness를 **내 프로젝트**에 설치해서 쓰는 최소 절차. 이 플러그인은 특정 프로젝트 전용이 아니라, 설치하는 어떤 프로젝트든 감싼다.

## 0. 준비물

- `claude` CLI (Claude Code)
- `python` (PATH에 있어야 함 — 훅이 `python`을 호출. 표준 라이브러리만 사용, 추가 설치 없음)

## 1. 설치

```bash
# 발행본
/plugin marketplace add https://github.com/kbigdata/omniharness
/plugin install omniharness

# 또는 로컬 경로로 바로 사용
claude --plugin-dir /path/to/omniharness
```

설치하면 그 프로젝트의 **모든 세션에 훅이 자동으로 붙는다**(위험명령 차단·완료검증 게이트·인계 주입·감사).

## 2. 프로젝트 스캐폴드

내 프로젝트 폴더에서:

```
/omniharness:init
```

깔리는 파일(기존 파일은 보존, 덮어쓰려면 아래 `--force`):

| 파일 | 역할 |
|---|---|
| `AGENTS.md` | 작업 헌법·위키 스키마 (자동 로드) |
| `.claude/settings.json` | 권한 deny/ask (훅과 2겹) |
| `feature_list.json` | 할 일(기능) 목록 — 완료 게이트 기준 |
| `claude-progress.txt` | 세션 인계 기록 |
| `wiki/`, `sources/` | 지식 위키 |
| `init.sh` | 개발환경 기동·스모크 (직접 채움) |

> Windows(PowerShell): `powershell -ExecutionPolicy Bypass -File "$env:CLAUDE_PLUGIN_ROOT/scripts/scaffold.ps1"`
> 강제 덮어쓰기: `bash "$CLAUDE_PLUGIN_ROOT/scripts/scaffold.sh" . --force`

## 3. 할 일 목록 채우기

`feature_list.json`을 목표 기능들로 채운다. 각 항목은 검증 전이므로 `passes:false`:

```json
[
  { "description": "greet.py 에 greet(name) 인사 함수 구현", "passes": false },
  { "description": "greet 에 대한 pytest 테스트 통과", "passes": false }
]
```

## 4. 작업 사이클 (한 세션 = 한 기능)

```
/omniharness:init 이후 반복:

1) 다음 기능 확인   →  python "$CLAUDE_PLUGIN_ROOT/scripts/next_feature.py"
2) 그 기능 구현
3) 독립 검증       →  /omniharness:verify <기능 설명>
                     (evaluator 서브에이전트가 PASS/FAIL 판정·기록)
4) PASS면 passes:true 로 바꾸고 커밋
5) claude-progress.txt 갱신 후 종료
```

- **검증(3)을 안 하면 종료가 막힌다** — `passes:true`인데 PASS 기록이 없으면 Stop 게이트가 차단.
- **미통과 기능이 남아도 종료가 막힌다** — 하다 말기 방지.

## 5. (선택) 자기개선 — 스킬·위키

```
/omniharness:skillify        # 성공한 재사용 절차 → 스킬 후보(격리됨)
/omniharness:promote <name>  # 사람 검토 후 스킬 활성화
/omniharness:wiki-ingest     # 검증된 지식을 위키에 기록
/omniharness:wiki-lint       # 위키 drift(오래됨·깨짐) 점검
```

## 무엇이 자동으로 강제되나 (요약)

| 항목 | 강제? |
|---|---|
| 위험명령·시크릿 차단 (`rm -rf`·`sudo`·`.env`) | 🔒 코드 |
| 검증기록 없는 완료 → 종료 차단 | 🔒 코드 |
| 미통과 기능 남으면 종료 차단 | 🔒 코드 |
| 도구호출 감사 (`.omniharness/audit.jsonl`) | 🔒 코드 |
| 스킬 격리·중복 거부, 승급은 사람 승인 | 🔒 코드 |
| 인계·위키 세션 시작 시 주입 | 🔁 자동 |
| 스킬/위키 *작성*, 규칙 *준수* | ✍️ 모델 몫(권고) |

## 문제 해결

- **훅이 안 도는 듯** → `python`이 PATH에 있는지 확인(`python --version`). 없으면 `python3` 별칭/링크.
- **종료가 자꾸 막힌다** → `feature_list.json`에 미통과 기능이 남았거나, 완료 기능의 `/omniharness:verify` 기록이 없다. 검증하거나 목록을 정리한다.
- **권한 프롬프트가 잦다** → `.claude/settings.json`의 ask 목록(`git push` 등) 때문. 필요시 조정.
