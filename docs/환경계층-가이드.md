# 환경 계층(Environment) 가이드 — Pattern A/B/C

> GAP §5/§8.5/§11 기준. omniharness는 **강제 계층(권한·훅)**까지 코드로 제공하지만,
> **환경 계층(OS/컨테이너/네트워크)은 인프라 영역**이라 *설정·가이드*로 제공한다.
> 핵심 규칙: **격리 없이는 `bypassPermissions` 금지** — `Project.agent_options(sandboxed=...)`가 코드로 강제.

## 3가지 운영 패턴

| | A: Approval-First | B: Curated Allow-list | C: Sandboxed Full-Auto |
|---|---|---|---|
| permission_mode | `default`(+정책) | `default`/`acceptEdits`(+정책) | `bypassPermissions` **+ sandboxed=True** |
| 환경 격리 | 없음 | 없음 | 컨테이너·비특권 사용자·네트워크 화이트리스트 |
| 용도 | 민감 코드 읽기 위주 | 일상 개발 | 야간 무인 자율 |

## bypass 가드 (코드 강제)
```python
proj.agent_options(permission_mode="bypassPermissions")              # → UnsafeConfigError
proj.agent_options(permission_mode="bypassPermissions", sandboxed=True)  # 격리 확인 시에만 허용
```

## 환경 격리 레시피 (패턴 C)
1. **컨테이너/devcontainer**: Docker로 작업트리만 마운트, `secrets/`·홈·자격증명 **미탑재**.
2. **비특권 OS 사용자**: 에이전트 프로세스를 별도 비특권 사용자로. `chmod 000`로 민감 디렉터리 보호.
3. **네트워크 화이트리스트**: Claude Code `settings.json`의 `sandbox.network.allowedDomains`로
   이그레스 제한 — `permissions`가 못 막는 `curl`을 여기서 막는다.
   ```json
   { "sandbox": { "enabled": true,
       "network": { "allowedDomains": ["api.anthropic.com"] },
       "filesystem": { "denyWrite": ["secrets/**"] } } }
   ```
4. **전체 도구호출 JSONL 로깅**(`.omniharness/audit.jsonl`) 후 아침에 감사 검토.

> 트레이딩 등 민감 도메인: 실거래 키·브로커 자격증명은 **에이전트 세계에 아예 존재하지 않게**
> (미탑재 컨테이너), 라이브 엔드포인트는 네트워크 화이트리스트에서 제외(백테스트/페이퍼만 노출).
